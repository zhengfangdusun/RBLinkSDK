Detailed Description

Callbacks run serially in an SDK-managed execution context, without holding SDK state locks. Do not wait for the application thread or call start, finish, cancel, or registration from a callback. Notify the application using a thread-safe queue. Storage callbacks must complete promptly.

int(* RBF_clone_evt_callbacks_t::read_chunk) (void *user, uint16_t seq, uint8_t *buffer, uint16_t capacity, uint16_t *size)

Import: fill buffer without exceeding capacity and set size, then return 0; return nonzero on missing data or failure. seq starts at 1. Repeated requests for a seq must return identical data. Required for import. Non-final chunks must be 234 bytes; the final chunk is 1..234 bytes. buffer is SDK-owned and valid only during the callback.

int(* RBF_clone_evt_callbacks_t::write_chunk) (void *user, uint16_t total, uint16_t seq, const uint8_t *data, uint16_t size)

Export: copy/take ownership of one chunk before returning 0; otherwise return nonzero. seq starts at 1 (SDK-local). total is 0 while exporting because the HUB does not announce a total. Save seq, size and original bytes. data is borrowed and valid only for this callback. Failed writes do not count as confirmed chunks. Required for export.
