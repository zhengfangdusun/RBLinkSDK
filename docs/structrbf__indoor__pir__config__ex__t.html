Detailed Description

Explicit extended configuration; the legacy structure and defaults stay intact. A zero pulse count selects the protocol default, otherwise use 1..15. LED disable fields accept only 0 (enabled) or 1 (disabled). Tamper detection and tamper LED are independent.
